# SIGESS — Landing Page

Site de apresentação/marketing do SIGESS para captação de novos clientes.

## Stack

React 19 + TypeScript + Vite · Tailwind CSS + shadcn/ui · React Router DOM · React Hook Form + Zod

## Início rápido

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

## Estrutura

```
src/
├── sections/    # Seções da página (Hero, Modules, Pricing, Contact…)
├── pages/       # Home, TermsOfUse, Utilities
├── components/  # Navbar, componentes UI
├── lib/         # generateREAPPdf, logoCache
└── hooks/
```
